# ✳ SW Client Studio

Премиальный интерактивный сервис для работы команды Siberian Wellness с клиентскими приглашениями, ответами и выгодами. Дизайн: жемчужно-белый фон, хвойная зелень, шампанское золото и матовое стекло.

## Что есть в сервисе

- **Быстрый подбор:** выбрать категорию человека и ситуацию, получить текст, переключить короткий/подробный вариант, подставить имя, при желании отредактировать и скопировать.
- **21 категория клиентов:** друзья, родственники, знакомые, коллеги, заочные знакомые, мама в декрете, спорт, косметика, выгодные покупки, холодные контакты и другие интересы и окружения.
- **147 сценариев приглашений:** по 7 на каждую категорию; для каждого есть короткая и подробная версия (всего 294 текстовых варианта).
- **Библиотека:** поиск, фильтры по категориям и ситуациям, избранное, постраничная подгрузка и копирование.
- **Выгоды:** кешбэк до 15%, подарки, клиентская регистрация и калькулятор по баллам и сумме покупки без НДС.
- **Возражения и FAQ:** удобные ответы на распространённые вопросы.
- **Глобальный поиск** и адаптация под мобильные устройства.

**Нет** CRM, карточек клиентов, личных кабинетов, клиентских баз или плана на 7 дней.

## Запуск и проверки

Node.js 20+:

```bash
npm install
npm run test:smoke
npm run dev
```

Сборка: `npm run build`. Проверка сборки: `npm run preview`.

Тест `test:smoke` проверяет все разделы, наличие категорий и семи сценариев в каждой, корректность данных и SSR-отрисовку, чтобы снизить риск публикации белого экрана.

## Публикация

GitHub Actions автоматически проверяет и публикует ветку `main` на GitHub Pages:

https://iliavsevolodov.github.io/swclients/

Если публикация не активна, проверьте Settings → Pages → Source: GitHub Actions.

## Редактирование контента

- `src/libraryData.js` — категории клиентов, все сценарии и их тексты.
- `src/data.js` — возражения, FAQ и информация о клиентских преимуществах.
- `src/App.jsx` — интерфейс и интерактивные функции.
- `src/styles.css` — фирменный стиль.

Изменения, отправленные в `main`, автоматически проходят тесты и сборку.

## Приватность

Регистрация не требуется. Сервис не хранит клиентские контакты и не содержит CRM. Избранные скрипты локально сохраняются в браузере пользователя. Сервис не отправляет переписку на сервер.

## Источники и аккуратность формулировок

Клиентские условия подготовлены на основе официального маркетинг-плана Siberian Wellness для России, 31-й бизнес-год, страница 9. Они могут меняться, поэтому актуальность проверяется на https://siberianwellness.com.

Кешбэк — бонусы на следующие покупки, а не перевод денег на карту. Процент считается от суммы без НДС и зависит от баллов покупок. БАДы не являются лекарствами, и рекламные формулировки не должны обещать лечение заболеваний.

Этот сервис — командная библиотека, а не официальный сайт Siberian Wellness.

## Публикация без белого экрана

GitHub Pages в этом репозитории запускает и стандартную публикацию из ветки `main` (Jekyll), и workflow приложения. Чтобы обе стратегии отдавали **рабочий сайт**, Vite теперь собирает отдельный HTML-шаблон `app/index.html` в `dist` с путями `/swclients/docs/assets/`. Workflow автоматически сохраняет собранный сайт в `docs/` ветки `main`. Корневой `index.html` перенаправляет пользователя на `docs/`, поэтому Jekyll больше не отдаёт сырой JSX.

Сайт доступен по адресу https://iliavsevolodov.github.io/swclients/ и по прямой ссылке https://iliavsevolodov.github.io/swclients/docs/ . Автоматические тесты выполняются перед публикацией.
