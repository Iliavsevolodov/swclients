# ✳ SW Client Studio

Интерактивный клиентский сервис команды Siberian Wellness, оформленный в стиле pearl white × forest green × champagne gold × frosted glass.

## Возможности

- Обзор — единое пространство со статистикой и прогрессом.
- Категории клиентов — 9 сегментов с советами и прямым переходом к подходящим сообщениям.
- Скрипты — 14 сценариев × 2 длины, фильтрация, персонализация имени и интереса, избранное, копирование.
- Выгоды — кешбэк, подарки, клиентская регистрация и реферальная программа, интерактивный калькулятор по баллам и сумме без НДС.
- Возражения — 12 ситуаций и экологичные варианты ответов.
- FAQ — 15 ответов по программе, регистрациям, баллам, подаркам и заказам.
- Мои клиенты — локальный мини-CRM: категории, этапы, заметки, дата следующего контакта и резервные копии JSON.
- План на 7 дней — обучение с сохранением прогресса.
- Глобальный поиск и адаптивная мобильная версия.

## Запуск

Node.js 20+.

    npm install
    npm run dev

Для выпуска: npm run build. Проверка: npm run preview.

## Публикация

В репозитории настроен workflow .github/workflows/deploy.yml. Откройте Settings → Pages → Build and deployment → Source: GitHub Actions.

После первого успешного деплоя адрес будет: https://iliavsevolodov.github.io/swclients/

Пока Pages не включён, этот адрес может не открываться. Для собственного домена измените base в vite.config.js.

## Редактирование контента

Вся учебная база хранится в src/data.js: audiences, scripts, objections, faqs, journey и benefits. Изменения файла в ветке main попадают в следующую автоматическую сборку.

## Важно о данных

Это безсерверный MVP. Карточки клиентов, избранное и прогресс сохраняются только в localStorage на конкретном устройстве. Между участниками команды данные НЕ синхронизируются и могут исчезнуть после очистки браузера. В CRM доступен экспорт/импорт JSON для личной резервной копии.

Не добавляйте в заметки медицинские, финансовые и другие чувствительные сведения. Получайте согласие клиента на хранение данных.

Для общей команды, авторизации и синхронизации потребуется backend (например, Supabase Auth/Postgres/RLS), а также соответствующие права доступа и условия обработки персональных данных. Сейчас они не реализованы.

## Сведения о программах

Основа контента: официальный «Маркетинг-план, 31-й бизнес-год, Россия», страница 9, и материал о Привилегированном клиенте. Сведения относятся к 2026 году. Проверяйте актуальные условия на https://siberianwellness.com.

Кешбэк начисляется бонусами для будущих заказов от суммы покупки без НДС. Пороги: 30 баллов — 5%, 50 баллов — 10%, 100 баллов — 15%. Срок реферальной акции в опубликованном документе — до 31 декабря 2026 года.

Этот продукт — обучающий сервис команды, а не официальный веб-сайт Siberian Wellness.
